Le plus simple maintenant est de ne pas installer Playwright sur le PC BNP. On va plutôt utiliser un module WebSocket déjà présent dans beaucoup d’environnements Node, s’il existe. Vérifie d’abord ces trois possibilités :
node -e "try { console.log('ws=',require.resolve('ws')) } catch(e) { console.log('WS_ABSENT') }"

node -e "try { console.log('undici=',require.resolve('undici')) } catch(e) { console.log('UNDICI_ABSENT') }"

node -e "try { const {WebSocket}=require('undici'); console.log('UNDICI_WEBSOCKET=',typeof WebSocket) } catch(e) { console.log('UNDICI_WEBSOCKET_ABSENT') }"
